## 📌 書籍購入補助の決まり事

会社から書籍購入の補助を受ける際のルールは以下の通りです。

- **月に１度まで**
- **１回５０００円までとし、端数がでたら実費**
- **申請のためにはGithubアカウントが必要（リポジトリへの招待が必要）**
- **月末までにISSUEを登録し、購入した書籍の領収書を添付すること（月末に承認のためのチェックを行うため）**

---

## 🐙 GitHubアカウントについて

書籍購入補助の申請には、GitHubアカウントが必要です。

1. **アカウントをお持ちでない場合**
   - [GitHub.com](https://github.com/) でアカウントを作成してください。
2. **アカウントをお持ちの場合**
   - 以下の手順で、プロフィール名を日本語に設定してください。
   - [🚀 はじめる前に：GitHubプロフィールの設定](#setting-profile)
   - リンク: [Githubアカウントの名前を変更](https://github.com/settings/profile)

## 🚀 はじめる前に：GitHubプロフィールの設定

書籍レポートの投稿者名を日本語で表示するには、GitHubプロフィールに名前を設定してください。

### 手順

1. **GitHubプロフィールページにアクセス**
   - GitHubにログイン → 右上のアイコンをクリック → 「**profile**」を選択

2. **プロフィールを編集**
   - 左側の「**Edit profile**」ボタンをクリック

3. **名前を入力**
   - 「**Name**」欄に日本語の名前を入力（例：杉本 光一）
   - 「**Save**」をクリック

> 💡 この設定は一度だけ行えばOKです。
