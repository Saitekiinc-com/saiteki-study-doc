# 📚 書籍購入補助を受ける前に

Saitekiの社員全員を対象とする書籍の購入補助制度です。

---

## 📌 書籍購入補助の決まり事

会社から書籍購入の補助を受ける際のルールは以下の通りです。

- **Saitekiの社員全員が購入補助を受けることができます**
- **月に１度まで申請可能です**
- **対象書籍は技術書、または自己啓発に関わる書籍とします**
- **それらに関連している内容であれば、漫画形式の書籍でもOKです**
- **１回５０００円までとし、端数がでたら実費となります**
- **申請のためにはGithubアカウントが必要です。各自作成をお願いします**
- **申請は購入月の月末までにGithub上で申請を行います。そこで購入する書籍の共有、そして領収書の添付（画像でOK）をしてください**
- **承認されれば翌月に給与と一緒に振り込まれます**
- **購入した書籍を読み終わったら、書籍レポートを作成してください。レポートを作成しないと翌月以降も書籍の購入補助を受けることはできません**

---

## 🐙 GitHubアカウントについて

書籍購入補助の申請には、GitHubアカウントが必要です。

1. **アカウントをお持ちでない場合**
   - [GitHub.com](https://github.com/) でアカウントを作成してください。
2. **アカウントをお持ちの場合**
   - 以下のリンクから、プロフィール名を日本語に設定してください。
   - リンク: [Githubアカウントの名前を変更](https://github.com/settings/profile)

> 💡 この設定は一度だけ行えばOKです。
