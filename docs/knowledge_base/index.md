# 書籍購入補助を受ける前に

Saitekiの社員全員を対象とする書籍の購入補助制度です。

## 書籍購入補助の決まり事

会社から書籍購入の補助を受ける際のルールは以下の通りです。

- **Saitekiの社員全員が購入補助を受けることができます**
- **月に1度まで申請可能です**
- **対象書籍は技術書、または自己啓発に関わる書籍とします**
- **それらに関連している内容であれば、漫画形式の書籍でもOKです**
- **1回5000円までとし、端数がでたら実費となります**
- **承認されれば翌月に給与と一緒に振り込まれます**
- **購入した書籍を読み終わったら、書籍レポートを作成してください**
- **レポートを作成しないと、翌月以降も書籍の購入補助を受けることはできません**

## 初めて使う場合

まず [Slackで書籍購入補助を申請する](/knowledge_base/slack_purchase_flow) を確認してください。

申請、購入承認、領収書提出、レポート提出、完了確認まで、利用者の操作はSlack上で行います。
