# 書籍レポートを蓄積のみを行う場合

自分で購入した本や、既に読んだ本について感想を投稿する場合のフローです。

## 📖 投稿フロー

| ステップ | 担当者 | アクション |
|---------|--------|-----------|
| 1 | **あなた** | [📚 書籍レポートを作成](./issue_book_report) |
| 2 | **自動** | PRが自動作成される |
| 3 | **上長** | PRをレビュー・マージ ([例](https://github.com/Saitekiinc-com/saiteki-study-doc/pull/173)) |
| 4 | **自動** | Slackに通知 ＆ ページが公開 |
