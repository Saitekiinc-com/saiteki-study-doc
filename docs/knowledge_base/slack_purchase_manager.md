# 上長向け操作ガイド

このページは、上長がSlackで書籍購入補助の申請を確認するための操作ガイドです。

## 確認する場所

申請が作成されると、書籍購入補助チャンネルに申請投稿が作成されます。

上長は、その投稿本文とスレッドを確認し、投稿に表示されているボタンで状態を進めます。

## 押すボタン

| 状態 | 確認するもの | 押すボタン |
|---|---|---|
| 購入承認待ち | 書名、書籍URL、対象月、購入目的 | `購入を承認` |
| 領収書確認待ち | スレッドに貼られた領収書画像 | `領収書を確認済みにする` |
| レポート確認待ち | スレッドに投稿されたレポート本文 | `レポートを確認して完了` |

ボタン操作の履歴は、誰が押したか分かるようにスレッドへ残ります。

レポートの修正が必要な場合は、利用者に申請投稿の `レポートを編集` から修正してもらいます。
編集後は、Slack上のレポート内容とGitHubに保存されるレポートデータが更新されます。

## レポート確認後

`レポートを確認して完了` を押すと、申請は完了になります。

完了した投稿には、見分けやすいようにチェックのリアクションが付きます。

## 間違えた場合

申請投稿に `一つ前に戻す` が出ている場合は、直前の操作を取り消せます。

たとえば、領収書確認を間違えて押した場合は、`一つ前に戻す` で前の状態に戻せます。
