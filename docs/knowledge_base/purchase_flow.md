# 書籍購入補助の流れ

書籍購入補助は、Slack上の申請投稿を中心に進めます。
利用者も上長も、基本的な操作はSlack上のボタン、スレッド、フォームで完結します。

## 全体像

```mermaid
flowchart TD
    A["利用者: Slackで申請する"] --> B["上長: 購入を承認する"]
    B --> C["利用者: 本を購入し、領収書をスレッドに貼る"]
    C --> D["利用者: 領収書を貼り付けました を押す"]
    D --> E["上長: 領収書を確認済みにする"]
    E --> F["利用者: レポートを書く"]
    F --> G["上長: レポートを確認して完了する"]
```
