# 書籍購入補助の流れ

書籍購入補助を受ける場合の手順と、書籍レポートのみを投稿する場合の手順について説明します。

## このページで分かること

- 購入補助を受ける場合に、申請者が何をすればよいか
- 領収書をどこに添付し、どのチェックボックスを入れればよいか
- 上長がどこを確認し、どのチェックボックスを入れればよいか
- 読了後の書籍レポート作成まで、どの順番で進むか
- 購入補助なしで書籍レポートだけ投稿する場合の流れ

## 購入補助を受ける場合の全体像

購入補助を受ける場合は、GitHub Issue を使って申請します。
最初に [AIで本を選んで申請する](./issue_book_search) ページから GitHub Issue を作成し、AIの推薦を参考に購入する本を決めます。
その後、領収書を Issue コメントに添付し、上長の確認を受けます。
読了後は、同じ書籍購入補助の手続きに紐づく形で [書籍レポートを提出](./issue_book_report) します。

AIの推薦はあくまで参考です。推薦された本以外を購入しても問題ありません。

## 申請者が行う手順

| ステップ | やること | 補足 |
|---:|---|---|
| 1 | GitHubアカウントを準備する | 申請にはGitHubアカウントが必要です。 |
| 2 | [AIで本を選んで申請する](./issue_book_search) | 学びたい内容や現在の課題を入力します。 |
| 3 | AI推薦を確認する | 1-2分ほどでコメントが投稿されます。 |
| 4 | 購入する本を決める | AI推薦は参考です。推薦外の本でも問題ありません。 |
| 5 | `購入したい書籍の商品リンクを添付した（申請者）` にチェックを入れる | 購入する本の商品リンクが Issue 上で分かる状態にしてからチェックしてください。 |
| 6 | 本を購入する | 購入月の月末までに申請を進めてください。 |
| 7 | 領収書を Issue コメントに添付する | 領収書は画像で問題ありません。 |
| 8 | `領収書を添付した (申請者)` にチェックを入れる | 領収書を添付した後にチェックしてください。 |
| 9 | 上長の承認を待つ | 上長が確認すると `承認済み (上長)` にチェックを入れます。 |
| 10 | 読了後に [書籍レポートを提出](./issue_book_report)する | 購入補助を受けた本は、読了後にレポート作成が必要です。 |
| 11 | 公開用PRの作成、レビュー、公開を待つ | 公開用PRが作成され、レビュー・マージ後にページが公開されます。 |

## 上長が行う手順

| ステップ | やること | 補足 |
|---:|---|---|
| 1 | 領収書と制度条件を確認する | 対象書籍、金額、購入月、領収書の内容を確認します。 |
| 2 | `承認済み (上長)` にチェックを入れる | 承認できる場合にチェックしてください。 |
| 3 | 書籍レポートの公開用PRを確認する | レポート内容を確認し、問題なければマージします。 |

## チェックボックスの意味

AIで本を選んで申請するために作成した Issue には、進捗を確認するためのチェックボックスが追加されます。

| チェックボックス | 入れる人 | 意味 |
|---|---|---|
| `購入したい書籍の商品リンクを添付した（申請者）` | 申請者 | 購入する本の商品リンクが Issue 上で確認できる状態です。 |
| `領収書を添付した (申請者)` | 申請者 | 領収書を Issue コメントに添付済みです。 |
| `承認済み (上長)` | 上長 | 上長が領収書と制度条件を確認し、承認済みです。 |

## 領収書添付時の確認ポイント

領収書は Issue コメントに添付してください。
コメント本文の書式は固定していませんが、次の内容が領収書から分かる状態にしてください。

- 購入日
- 購入金額
- 購入先
- 購入した書籍が分かる情報

領収書は画像添付で問題ありません。
領収書を添付した後に、`領収書を添付した (申請者)` にチェックを入れてください。

## 書籍レポートのみ投稿する場合（購入補助なし）

自分で購入した本や、既に読んだ本について感想を投稿する場合のフローです。

| ステップ | 担当者 | アクション |
|---------|--------|-----------|
| 1 | **あなた** | [書籍レポートを提出](./issue_book_report) |
| 2 | **自動** | 公開用PRが自動作成される |
| 3 | **上長** | 公開用PRをレビュー・マージ ([例](https://github.com/Saitekiinc-com/saiteki-study-doc/pull/173)) |
| 4 | **自動** | Slackに通知 ＆ ページが公開 |

## よくあるつまずき

### AI推薦以外の本でもよいですか？

問題ありません。AIの推薦は参考です。
推薦外の本を選んだ場合でも、毎回選定理由を書く必要はありません。

### 領収書は画像でよいですか？

画像で問題ありません。
購入日、購入金額、購入先、購入した書籍が分かる状態で添付してください。

### 商品リンクと領収書は同じタイミングで添付してよいですか？

同じタイミングでも問題ありません。
その場合も、商品リンクが Issue 上で分かる状態にし、領収書をコメントに添付した後で該当するチェックボックスを入れてください。

### 購入候補や推薦外書籍の選定理由を毎回コメントする必要はありますか？

必須ではありません。
ただし、上長が確認しやすいように、購入する本の商品リンクは Issue 上で確認できる状態にしてください。

### 申請後に本を変えたい場合はどうすればよいですか？

購入前であれば、Issue 上で購入する本が分かるように更新してください。
すでに購入済みの場合は、領収書の内容と購入した本が一致しているかを上長が確認できる状態にしてください。

### 書籍レポートはいつ作りますか？

購入した本を読み終わった後に作成してください。
レポートを作成しないと、翌月以降も書籍の購入補助を受けることはできません。

### 間違えてIssueを作った場合はどうすればよいですか？

間違えて作成した場合や、途中で不要になった場合は [Issueを閉じたい場合](./issue_close) を確認してください。

### 公開用PRが作られない場合はどうすればよいですか？

しばらく待っても公開用PRが作成されない場合は、Issueの入力内容やラベルが正しく付いているかを確認してください。
自分で判断できない場合は、上長または管理者に相談してください。
