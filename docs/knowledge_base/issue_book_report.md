# 書籍レポートを提出する

購入補助を受けた本は、読了後に書籍レポートを提出します。
レポートはSlackの申請投稿から提出します。

## 提出するタイミング

上長が領収書を確認すると、申請投稿の状態が `読了・レポート提出待ち` に変わります。

この状態になると、申請投稿に `レポートを書く` が表示されます。

## 提出方法

1. 自分の申請投稿を開く
2. `レポートを書く` を押す
3. フォームに入力する
4. 送信する

送信すると、レポート本文が申請スレッドに投稿されます。

## 入力する項目

| 項目 | 説明 | 例 |
|-----|------|-----|
| **書籍名** | 読んだ本のタイトル | リーダブルコード |
| **氏名** | レポートのAuthorとして表示する名前 | 杉本光一 |
| **著者** | 著者名 | Dustin Boswell |
| **リンク** | Amazon、出版社、書店などのURL | https://amazon.co.jp/... |
| **読む前の目的** | なぜこの本を読もうと思ったか | コードの可読性を向上させたい |
| **得られた知識** | この本で何がわかったか | 命名規則の重要性 |
| **実務における活用** | 明日から何を変えるか | 関数名に動詞を使う |
| **良かった点** | なぜ良かったのか | 具体例が豊富 |
| **難しかった点・合わなかった点** | 読みづらかった点 | 特になし |
| **どんな人におすすめか** | どんな人に読んでほしいか | チームリーダー、React初心者 |

## 提出後に起きること

レポートを送信すると、状態が `レポート確認待ち` になります。

上長が内容を確認して `レポートを確認して完了` を押すと、申請が `完了` になります。

完了後、レポートはナレッジベースに保存されます。

## よくある質問

### GitHubを開く必要はありますか？

利用者は基本的に開く必要はありません。

レポートは裏側でGitHubに保存されますが、提出と確認はSlack上で行います。

### レポートを書き直したい場合はどうしますか？

上長確認前であれば、申請スレッドで修正したい内容を伝えてください。

完了後に修正が必要な場合は、上長または管理者に相談してください。
